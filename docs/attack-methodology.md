# Attack Methodology

The attack library focuses on adversarial inputs that attempt to override the intended behavior of an AI application.

## Families

- Prompt injection
- Indirect prompt injection
- Data extraction
- RAG poisoning
- Tool abuse
- Jailbreak testing

## Operational goal

The goal is not to demonstrate harmful behavior in real systems. The goal is to measure how well security controls detect, block, and recover from adversarial attempts in a sandboxed environment.
