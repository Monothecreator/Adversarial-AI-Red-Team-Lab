# Evaluation Methodology

Each test is scored using a simple risk model.

## Inputs

- Attack success or blocking result
- Severity level
- Asset sensitivity of the target
- Control effectiveness

## Scoring approach

The risk engine converts attack outcomes into a security score, with higher values indicating stronger defenses.

- Success against a weak control = lower security score
- Blocked attack = higher score
- Failed attack = neutral or low risk signal

## Reporting

The platform produces a scored assessment with category-level and overall risk values.
